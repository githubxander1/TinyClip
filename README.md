# 轻剪贴 (TinyClip)

轻量、独立的 Windows 悬浮剪贴板。常驻桌面，记录复制过的文本、图片和文件，方便稍后再次粘贴。无需 Quicker，不联网，也不需要安装。

建议 GitHub 仓库名：`tinyclip`。

## 功能

- 自动记录复制的文本、图片和文件；点击记录即可重新放入系统剪贴板。
- 图片记录提供预览。复制单个 PNG、JPEG、BMP、GIF 或 TIFF 图片文件时，也会尝试生成预览，同时保留原文件路径供文件粘贴使用。
- 文本记录支持手动新增、右键编辑和多行内容。
- 单条记录可独立置顶，置顶记录排在普通记录前；收藏与置顶互不影响。
- 支持按全部、文本、图片、文件和收藏筛选，也可搜索记录内容与文件名。
- 悬浮面板支持置顶、收起、拖动、调整大小、暂停记录和托盘控制。
- 支持快捷键 `Ctrl+Alt+V` 展开或收起，`Esc` 收起。
- 支持设置开机启动、失焦自动收起、悬浮按钮尺寸和普通历史条数。

## 运行

从 GitHub Release 下载并解压后，运行 `轻剪贴.exe`。程序不要求管理员权限。

也可以自行编译：编译生成 `build\TinyClip.exe`，将它改名为 `轻剪贴.exe` 后运行。程序默认把 `Data` 目录放在可执行文件旁；移动程序时请将 `Data` 一并移动。

可选参数 `--data-dir` 用于指定数据目录：

```powershell
.\轻剪贴.exe --data-dir "D:\MyClipData"
```

## 快捷操作

| 操作 | 说明 |
| --- | --- |
| 点击记录 | 将记录复制回系统剪贴板，再到目标应用粘贴 |
| 右键文本记录 | 编辑、复制纯文本、查看全文、置顶、收藏或删除 |
| 点击记录右侧图钉 | 单独置顶或取消置顶该记录 |
| 点击标题栏图钉 | 切换悬浮窗口的系统置顶状态 |
| `Ctrl+Alt+V` | 展开或收起面板 |
| `Esc` | 收起面板 |

## 本地数据与隐私

- 程序不联网，不会将剪贴板内容上传到服务器。
- 历史记录保存在 `Data\history.dpapi`，使用 Windows 当前用户的 DPAPI 加密。其他 Windows 用户或其他电脑通常无法解密这份历史数据。
- 窗口位置和使用偏好保存在 `Data\preferences.json`。
- 文件记录只保存路径，不会复制文件本体。源文件移动或删除后，原文件无法通过历史记录恢复；图片预览数据仍保存在记录中。
- 遇到 Windows 的“禁止剪贴板历史”标记时会跳过该内容。

## 容量限制

- 单条记录最大约 6 MiB，历史内容总量最大约 24 MiB。
- 普通历史默认保留 100 条，可在菜单调整为 50、100 或 200 条。
- 收藏最多 100 条；空间不足时优先移除最旧的未收藏记录。
- “清空”只清除未收藏记录；“清空全部”会同时清除收藏和磁盘历史。

## 从源码编译

### 环境要求

- Windows 10 或 Windows 11
- .NET Framework 4.8
- Windows 自带的 .NET Framework C# 编译器

源码使用 C#、WPF 和 Win32 剪贴板监听，没有第三方运行时依赖。在项目根目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

编译产物为 `build\TinyClip.exe`。`build.ps1` 会调用 Windows .NET Framework 编译器，不会下载依赖或访问网络。

## 项目结构

```text
src/             C# 源码
  Program.cs     程序入口与单实例控制
  MainWindow.cs  悬浮窗口、记录列表与交互
  ClipboardService.cs 剪贴板读取和写入
  Models.cs      记录、历史和本地存储
  Native.cs      Win32 API 声明
build.ps1        本地编译脚本
app.manifest     Windows DPI 和权限配置
```
